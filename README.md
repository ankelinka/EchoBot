![Python](https://img.shields.io/badge/python-3670A0?style=for-the-badge&logo=python&logoColor=ffdd54)

## Установка:

```sh
1. в консоле: git clone https://github.com/ankelinka/EchoBot.git
2. создайте файл ".env" и создайте в нем переменную "BOT_TOKEN", где будет указан токен вашего бота. / пример: "BOT_TOKEN = 1234567890:AABBCCDDEEFFGGHHIIGGKK"
3. в консоле: pip instal -r requirements.txt
```
